- `forest.primary`: `#2D4A2B`
- `forest.onPrimary`: `#FFFFFF`

- `forest.coral`: `#A84F3E`

All UI code consumes semantic Material color roles. These values are source colors, not direct component styling.

## Spacing

`4`, `8`, `12`, `16`, `20`, `24`, `32` dp. Screen gutters are 16 dp on compact phones.

## Shape

- Small: 10 dp
- Control: 14 dp
- Card: 18 dp
- Focus surface: 24 dp

## Typography

- Display and major headings: serif, bold or semibold.
- Body, labels, controls, and data: sans-serif.
- Use Material type roles and scalable `sp`; no per-screen arbitrary type sizes.
