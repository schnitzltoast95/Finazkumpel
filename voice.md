# Voice

- Write in direct, conversational German using “du”.
- Prefer everyday actions: “eintragen”, “ergänzen”, “hinterlegen”, “prüfen”.
- A control names the result: “Tagesabschluss speichern”, not “OK”.
- Errors state what failed and what the user can do next.
- Never claim tax correctness or completeness; distinguish “hinterlegt” from “steuerlich vollständig”.
- Keep labels short and sentence case. Avoid filler, sales language, and unexplained bookkeeping terms.
